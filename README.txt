VEER SMRITI — REDESIGNED WEBSITE (EARLY EDITION)
================================================

OPEN LOCALLY
1. Download and extract the ZIP file.
2. Open the folder named veer-smriti-redesigned.
3. Double-click index.html. It should open in Microsoft Edge or Chrome.
4. Keep the assets folder beside index.html; it contains the panoramic hero image, the new soldier-only brand symbol, and the browser icon.

WHAT IS INCLUDED
- Warm ivory, muted gold and green visual system
- New soldier-only logo symbol featuring the soldier, sunrise, mountains and Indian tricolour (no lettering inside the symbol)
- Responsive homepage with the panoramic India landscape
- Veer Smriti principle and editorial promise
- Searchable story archive with service, story-type and period filters
- Individual story reading view with documented-record and family-remembrance perspectives
- Reflection, next-story discovery and optional contribution invitation at each story's end
- Contribution form that creates a local text draft only; it does not upload or send any information
- Responsive navigation and keyboard-dismissable story view
- SEO basics and accessibility-minded labels

IMPORTANT EDITORIAL NOTES
- This is an early prototype, not a deployed website.
- The starter entries are not a complete archive. Verify claims against exact sources before publishing.
- The source links currently point to institutional starting points, not exact citations for every claim. Replace them with direct award citations, official records, or reliable historical references before public launch.
- No family testimony has been invented. The family-remembrance section explains how real testimony could be included with consent and attribution.
- The “A family’s remembrance” card is a format demonstration only, not a real person or real testimony.
- The contribution form only prepares a local .txt draft in the visitor's browser. It does not send data to Veer Smriti. Do not ask visitors to send sensitive, private or operationally sensitive material until a secure process is designed.
- Veer Smriti is an independent project and is not an official Government of India or Armed Forces website.
- No story count target or popularity ranking is used.

BEFORE PUBLIC LAUNCH
1. Verify each story claim and replace general source links with exact citations.
2. Add individual article pages / clean URLs if desired.
3. Build a secure, consent-aware contribution and correction process before collecting submissions.
4. Review permissions for photographs, letters and family testimony.
5. Test on mobile and desktop, and check accessibility and privacy wording.
6. Upload the contents of this folder to the root of the GitHub repository and enable GitHub Pages.
